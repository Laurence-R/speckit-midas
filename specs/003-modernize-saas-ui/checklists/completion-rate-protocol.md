# Completion-Rate Protocol

## Objective
Compare task-flow completion before and after UI modernization.

## Scenarios
- S1: Add a stock and open detail page.
- S2: Find an event and trigger AI analysis.
- S3: Update setting value and verify saved feedback.

## Measurement
- Completion rate = completed runs / total runs
- Baseline runs: 10 per scenario before UI change
- Post-change runs: 10 per scenario after UI change

## Acceptance
- Overall completion-rate drop must be <= 5%
- No scenario may drop by > 10%

## Reporting
Record baseline in completion-rate-baseline.md and comparison in completion-rate-comparison.md.
