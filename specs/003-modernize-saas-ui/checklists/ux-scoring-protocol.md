# UX Scoring Protocol

## Objective
Evaluate visual quality improvements with a repeatable 100-point rubric.

## Rubric
- Visual hierarchy clarity: 0-25
- Theme consistency (dark/light): 0-20
- Information density efficiency: 0-20
- Interaction state clarity: 0-20
- Accessibility readability (contrast): 0-15

## Method
1. Score each target page: dashboard, stock detail, watchlist, settings, resource monitor.
2. Compute weighted average across all pages.
3. Success threshold: overall >= 85 and no single dimension < 12.

## Recording format
- Date
- Reviewer
- Per-page scores
- Overall score
- Notable issues and remediation notes
