# Implementation Plan: Modernize SaaS UI Tone and Layout

**Branch**: `003-modernize-saas-ui` | **Date**: 2026-05-23 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/003-modernize-saas-ui/spec.md`

## Summary

本功能在不改動既有資料流程與功能行為前提下，升級 Midas 的 UI 視覺語言為現代化專業 SaaS 風格，並以中高密度排版改善過多留白。實作重點為：
- 深色/亮色主題同步升級並維持一致語意角色
- WCAG AA 對比達標（4.5:1 / 3:1）
- spacing token（S/M/L）驅動全站留白規則
- 元件狀態（default/hover/focus/disabled）與狀態語意色一致化

## Technical Context

**Language/Version**: Python 3.12  
**Primary Dependencies**: customtkinter, pytest (現有專案依賴，不新增框架)  
**Storage**: N/A（本功能不變更 SQLite schema）  
**Testing**: pytest（現有 unit 測試） + 手動視覺驗收清單  
**Target Platform**: Windows 10/11 桌面應用  
**Project Type**: desktop-app (CustomTkinter)  
**Performance Goals**: 保持既有頁面切換體驗；視覺改版不造成可感知互動延遲  
**Constraints**:
- 僅允許 UI 視覺層改動（色彩、色調、排版）
- 不修改 service/repository/integration 邏輯
- 深色與亮色模式都必須完成
- 文字對比需達 WCAG AA
**Scale/Scope**:
- 覆蓋 5 個主要頁面（dashboard/stock-detail/watchlist/settings/resource-monitor）
- 覆蓋共用元件（sidebar/status bar/cards/list items）

## Phase 0: Research Output

已完成 [research.md](research.md)，關鍵決策：
1. 語意化色彩角色管理，不允許元件硬編碼 HEX。
2. 中高密度策略 + spacing token（S/M/L）作為留白驗收基準。
3. WCAG AA 對比驗收（4.5:1 / 3:1）。
4. 深色與亮色同步改版。
5. 嚴守 UI-only 變更邊界，不跨層改動資料流程。
